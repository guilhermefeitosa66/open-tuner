A tuner that only tunes.

Pluck a string and OpenTuner tells you if it is loose, too tight or in tune. Ukulele, guitar, bass and their cousins. That's all it does.

How it works

Look at one line

The center line is the note. The marker shows how far the string is from it, in cents, and the trail below shows how you got there.

Left of the line

Loose

The string sounds lower than the note. Tighten it and the marker walks right.

On the line

In tune

Keep it there for a moment: a green ring closes around the marker, a chime plays and the string gets a green check. Move on to the next one.

Right of the line

Too tight

The string sounds higher than the note. Loosen it a little. Yellow means you are close.

All strings in tune? Start over clears the checks, to tune another instrument or check them all again.

Instruments

Standard tuning is already picked

Privacy and code

It only listens, and only while you tune

Microphone, and nothing else

The microphone is the only permission OpenTuner asks for. Sound is analyzed in memory as you play and thrown away. It is never recorded, and the app has no internet permission, so it could not send anything even if it wanted to. It works offline, always.

Download

Install it from GitHub

Each version is published on GitHub Releases as APK files, for Android 7.0 or newer. Google Play is coming soon.

Which file to pick

  • arm64-v8aMost phones
  • armeabi-v7aOlder 32-bit ARM phones
  • x86_64Chromebooks and emulators

The architecture is at the end of the file name. The first time, Android may ask you to allow installing apps from your browser or file manager.
